# 事件上报配置优化验收

## 范围

沿用 `businessDefinitions`、`events.track`、Customer UUID 和浏览器短期凭证协议。未改数据库结构、幂等键、事件历史、营销频控或内置生产者。保留同一工作区中上一轮未提交的 Notifuse 适配修改，未创建分支或 commit。

具体使用方法见[配置指南](../guides/configurable-marketing.md#事件上报配置流程)。

## 改善内容

- 将自定义事件配置分成上报权限、客户/业务对象、有效期；互斥上报方式，精确 Origin 校验，明确“全部来源”和“受限来源”。
- 友好时长单位但不改底层秒值；尊重旧的 required 默认语义及显式 expires_at 优先级。
- 分开草稿保存与启用；不新增审批，也不允许带不完整配置启用。后端采用同一完整性边界，直接 API 调用也不能绕过。
- 增加字段驱动样例、外部映射样例和请求/SDK 接入说明；不覆盖手写样例、不实发。
- 校验结果只绑定当前输入；修改、工作区切换或关闭后不会展示旧请求结果。保存期间防重并禁止修改，关闭前提示丢弃未保存输入。
- 可选路径清空真正移除设置；修正客户 UUID 映射键为 customer_id。服务端按实际对象路径语法校验，并在样例中检查对象编号与属性。
- 批量扩展显式选目标、冲突预告、动态示例、防重复覆盖；服务端原子事务语义不变。
- 新增 89 条界面文案，英文/简体中文完整，其他七种语言提供可编辑英文回退；保留原词条与之前的修改。

## 验证

- Go `./internal/... ./pkg/... ./config/... -count=1`：最终复验 5,010 个顶层测试通过，无失败；原有数据库/外部服务条件跳过仍存在，不声称全量数据库集成验收。
- Go domain/service/http 最终针对性复跑通过，覆盖冲突配置、允许来源、单位/有效期、映射、样例无写入、HTTP 400 字段定位及过期语义。
- Console business 组件和 business API 最终回归：55 项通过，覆盖迟到响应、跨工作区、未保存保护、草稿/启用、防重、映射路径、客户/到期必需映射、生成样例和字段扩展。
- Lingui compile、TypeScript、ESLint、Console 生产构建及 `git diff --check` 通过。仍保留既有构建大包提醒；本轮未宣称全量前端历史失败已修复。

### 浏览器

使用 Playwright 访问真实 React 页面与实际 `BusinessConfigService` / HTTP handler。仅用内存 repository 和测试身份，不连接原开发数据库，也未调用 `events.track`、浏览器采集、Provider 或商业 AI。

已验证：

1. 90 秒切到分钟显示 1.5；没有配置改动。
2. 浏览器模式缺 Origin 时保存被拦截、字段显示中文错误；输入 `https://app.example.com/` 后规范化为 `https://app.example.com`。
3. 生成嵌套对象样例，经实际后端预览得到 accepted；reported_at 由后端产生，expires_at 为 triggered_at + 90 秒。
4. 保存重开得到 revision 2、browser_enabled=true、authoritative=false、ttl_seconds=90；接入说明按存储配置生成。
5. 修改名称后关闭出现丢弃确认；选择继续编辑后名称保留。
6. 390×844 窄屏下抽屉不横向溢出，底部保存和关闭入口可用。

本地证据在 `output/playwright/event-reporting/.playwright-cli/`：测试 JSON/构建日志、临时 Go API 夹具及截图。`element-2026-09-21T07-01-34-354Z.png` 展示后端样例校验，`page-2026-09-21T07-02-33-750Z.png` 展示保存重开后的配置，`page-2026-09-21T07-03-14-601Z.png` 展示窄屏接入说明。文件不进入版本库。

开发热更新曾触发已有 LocaleProvider 的模块热替换问题，完整重载后继续验证；测试夹具未实现用户语言持久化 API。两项都不作为事件配置后端验证证据。

验证完成后已关闭浏览器会话、Vite 和本轮测试容器；保留本地证据文件。

## 兼容说明

不补写存量定义，不重解释旧事件。启用或再次保存不合规活动定义时须修正配置；草稿仍可保存未完成的必填项，原有无效事件可以归档。路径只支持实际实现的对象字段访问，不宣称支持 JSONPath 数组/通配符。真正的客户身份归属、对象所有权、幂等冲突、浏览器凭证和外部数据写入仍由正式上报链路检查。
